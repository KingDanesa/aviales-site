==================================================================
   ИНСТРУКЦИЯ ПО САЙТУ РГКП «КАЗАВИАЛЕСООХРАНА»
   (aviales-site)  —  как менять контент, как работает админка
==================================================================

Документ описывает, КАК и ГДЕ менять содержимое сайта, как добавлять
авиаотделения, новости, вакансии, как пользоваться админ-панелью и как
выкладывать изменения в интернет.

Файл можно открывать в Блокноте, но удобнее в VS Code.


==================================================================
0. КОРОТКО О ГЛАВНОМ
==================================================================

- Сайт сделан на Next.js (React). Это НЕ обычный HTML/PHP-сайт —
  его нельзя просто «залить по FTP». Чтобы он работал, нужен Node.js.
- Контент бывает ДВУХ видов:
    1) ПОСТОЯННЫЙ (структура, отделения, техника, руководство, цифры,
       тексты) — хранится в файлах проекта. Меняется в коде и
       выкладывается через GitHub → Vercel.
    2) ДИНАМИЧЕСКИЙ (новости, вакансии) — хранится в базе данных и
       меняется через АДМИН-ПАНЕЛЬ прямо в браузере, без программиста.
- Сайт сейчас живёт на Vercel: https://aviales-site.vercel.app
  Исходный код на GitHub: https://github.com/KingDanesa/aviales-site
- Языки сайта: русский (ru), казахский (kz), английский (en).


==================================================================
1. ЗАПУСК САЙТА НА СВОЁМ КОМПЬЮТЕРЕ (для просмотра/правок)
==================================================================

Нужен установленный Node.js (https://nodejs.org, версия 20 или новее).

1) Открыть папку проекта в терминале:
       C:\Users\user\Desktop\aviales-site
2) Один раз установить зависимости:
       npm install
3) Запустить локальный сервер:
       npm run dev
4) Открыть в браузере:
       http://localhost:3000

Пока сервер запущен, любые изменения в файлах применяются сразу
(страница сама обновляется). Остановить сервер — Ctrl + C в терминале.


==================================================================
2. ГДЕ ЧТО ЛЕЖИТ (карта проекта)
==================================================================

Папка с данными, которые чаще всего меняют:
   src\lib\
       siteStats.ts        — цифры на главной (год, часы, площадь)
       branches.ts         — список авиаотделений (адреса, начальники, карта)
       structure.ts        — данные оргсхемы (страница «Структура»)
       structureI18n.ts    — переводы оргсхемы на KZ/EN

Тексты и переводы интерфейса:
   messages\ru.json        — все русские тексты сайта
   messages\kz.json        — казахские
   messages\en.json        — английские

Страницы сайта:
   src\app\[locale]\page.tsx           — Главная
   src\app\[locale]\about\page.tsx     — О предприятии
   src\app\[locale]\leadership\page.tsx— Руководство
   src\app\[locale]\branches\page.tsx  — Филиалы и отделения
   src\app\[locale]\equipment\page.tsx — Авиационная техника
   src\app\[locale]\structure\page.tsx — Структура предприятия
   src\app\[locale]\state\page.tsx     — Государственная символика
   src\app\[locale]\contacts\page.tsx  — Контакты
   src\app\[locale]\news\page.tsx      — Новости
   src\app\[locale]\vacancies\page.tsx — Вакансии

Картинки, гимн, флаг, герб и т.п.:
   public\                 (флаг kz-flag.svg, герб kz-emblem.svg,
                            гимн kz-anthem.mp3, логотип logo.gif и др.)

Админка (код):
   src\app\admin\          (страница входа и панель управления)

ВАЖНО: после правки .ts / .json файлов изменения попадут на сайт только
после ВЫКЛАДКИ (раздел 9). Локально (npm run dev) видно сразу.


==================================================================
3. КАК ИЗМЕНИТЬ ЦИФРЫ НА ГЛАВНОЙ (1978 / 18 / 9000 / 6.5М)
==================================================================

Файл:  src\lib\siteStats.ts

Внутри:
   export const siteStats = {
     foundedYear: '1978',     // год основания
     branchesCount: ...,       // считается АВТОМАТИЧЕСКИ (не трогать)
     flightHours: '9000',     // налётных часов в год
     protectedArea: '6.5М',   // площадь лесов под охраной
   };

- Чтобы изменить ГОД — поменяй '1978' на нужный.
- Чтобы изменить НАЛЁТНЫЕ ЧАСЫ — поменяй '9000'.
- Чтобы изменить ПЛОЩАДЬ — поменяй '6.5М' (можно '7М', '6.8 млн' и т.п.).
- КОЛИЧЕСТВО ОТДЕЛЕНИЙ менять здесь НЕ нужно — оно само берётся из
  списка отделений (см. раздел 4). Добавишь отделение — станет 19.

Важно: текст пишется в кавычках. Не удаляй кавычки и запятую в конце.


==================================================================
4. КАК ДОБАВИТЬ / ИЗМЕНИТЬ АВИАОТДЕЛЕНИЕ
==================================================================

Файл:  src\lib\branches.ts

Там массив `branches`. Каждое отделение — один блок в фигурных скобках { }.
Пример одной записи:

   {
     id: 'almaty',
     name: { ru: 'Алматинское', kz: 'Алматы', en: 'Almaty' },
     region: { ru: 'г. Алматы', kz: 'Алматы қ.', en: 'Almaty city' },
     address: { ru: 'г. Алматы, ул. Мереке, 24', kz: '...', en: '...' },
     head: 'Байшалов Бекзат Ерденович',
     role: { ru: 'Начальник авиаотделения', kz: '...', en: '...' },
     phones: ['8708 338 6812', '8771 993 6143'],
     email: 'Almaty@aviales.kz',
     lat: 43.24,   // широта  (для точки на карте)
     lng: 76.89,   // долгота (для точки на карте)
   },

ЧТОБЫ ДОБАВИТЬ НОВОЕ ОТДЕЛЕНИЕ:
1) Скопируй любую существующую запись (от { до }, включая запятую).
2) Вставь её в список (например, перед закрывающей строкой "];").
3) Поменяй поля:
   - id — короткое уникальное имя латиницей без пробелов (например 'shymkent').
   - name / region / address / role — заполни на 3 языках (ru, kz, en).
   - head — ФИО начальника, phones — телефоны (в квадратных скобках,
     через запятую), email — почта.
   - lat / lng — координаты города (можно взять на 2gis или Google Maps:
     правый клик по точке → координаты; первое число это lat, второе lng).
4) Сохрани файл.

ЧТО ОБНОВИТСЯ САМО:
   • счётчик «18 авиаотделений» в статистике станет «19»;
   • заголовок «18 авиаотделений по всему Казахстану»;
   • новая точка появится на карте Казахстана (на главной и в «Филиалах»);
   • карточка отделения в списке «Филиалы и отделения».

ЧТОБЫ ИЗМЕНИТЬ ОТДЕЛЕНИЕ — просто поправь нужные поля в его записи.
ЧТОБЫ УДАЛИТЬ — удали весь блок от { до } вместе с запятой.

Подсказка: запятые и кавычки важны. Если сайт «сломался» после правки —
скорее всего пропущена кавычка/запятая/скобка.


==================================================================
5. КАК ИЗМЕНИТЬ ОРГСХЕМУ (страница «Структура»)
==================================================================

Данные:    src\lib\structure.ts
Переводы:  src\lib\structureI18n.ts

В structure.ts — дерево: директор → заместители → службы → звенья →
авиаотделения и отделы. У каждого блока:
   name   — название
   total  — «всего N ед.»
   posts  — список должностей: [['Должность', 'кол-во'], ...]
   k      — тип блока (цвет): director, deputy, service, link, airbase, office
   children — вложенные блоки

Чтобы изменить штатную единицу — поправь число в posts или total.
Чтобы добавить должность — добавь строку ['Название', '1'] в posts.

ПЕРЕВОДЫ: если добавляешь НОВОЕ название отдела/должности, добавь его
перевод в src\lib\structureI18n.ts в объект DICT:
   'Русский текст': { kz: 'Казахский', en: 'English' },
Если перевода нет — на других языках покажется русский текст.

==================================================================
8. КАК ИЗМЕНИТЬ ТЕКСТЫ, КОНТАКТЫ, АДРЕС
==================================================================

Большинство текстов интерфейса — в файлах переводов:
   messages\ru.json   (русский)
   messages\kz.json   (казахский)
   messages\en.json   (английский)

Правило: один и тот же «ключ» есть во всех трёх файлах. Меняешь текст —
меняй во всех трёх (иначе на каком-то языке останется старый).

Контакты (телефон, e-mail, адрес) встречаются:
   - messages\*.json  (поля cta.subtitle, footer.desc, contactsPage.*)
   - src\app\[locale]\contacts\page.tsx  (карточки адреса и карта)
   - src\app\[locale]\about\page.tsx     (блок «юр./факт. адрес»)
   - src\components\HomeContact.tsx       (форма + карта на главной)


==================================================================
9. КАК ВЫЛОЖИТЬ ИЗМЕНЕНИЯ В ИНТЕРНЕТ (GitHub → Vercel)
==================================================================

После правки файлов изменения надо «запушить» на GitHub. Vercel сам
пересоберёт сайт за пару минут.

В терминале в папке проекта по очереди:

   git add -A
   git commit -m "краткое описание что изменили"
   git push

После этого зайти на https://vercel.com → проект aviales-site →
вкладка Deployments → дождаться статуса Ready. Готово, сайт обновлён.

ЕСЛИ git ругается на авторизацию — при первом push откроется окно
входа в GitHub, нужно войти под аккаунтом, у которого есть доступ к репо.

10. АДМИН-ПАНЕЛЬ (новости и вакансии)
==================================================================

АДРЕС ВХОДА:
   https://aviales-site.vercel.app/admin
   (локально: http://localhost:3000/admin)

ЛОГИН И ПАРОЛЬ (временные, демо):
   E-mail:  admin@aviales.kz
   Пароль:  admin123

После входа открывается панель с разделами слева:
   • Дашборд   — общая сводка (сейчас цифры демонстрационные).
   • Новости   — создание и удаление новостей.
   • Вакансии  — создание и удаление вакансий.
   • Сообщения — входящие с формы обратной связи.

КАК ДОБАВИТЬ НОВОСТЬ:
   1) Раздел «Новости» → кнопка «+ Создать новость».
   2) Заполнить заголовок и текст на 3 языках (RU/KZ/EN),
      выбрать категорию, при желании вставить ссылку на картинку (URL).
   3) Нажать «Опубликовать» (сразу на сайт) или «Сохранить черновик».
   4) Новость появится в списке и в разделе «Новости» на сайте.

КАК УДАЛИТЬ НОВОСТЬ/ВАКАНСИЮ:
   В списке нажать значок корзины 🗑️ и подтвердить.

КАК ДОБАВИТЬ ВАКАНСИЮ:
   Раздел «Вакансии» → «+ Добавить вакансию» → заполнить → «Сохранить».

ВАЖНО про админку:
   • Новости и вакансии хранятся в БАЗЕ ДАННЫХ (см. раздел 11). Если база
     недоступна — список не загрузится и добавление не сработает.
   • Картинки в новостях вставляются ССЫЛКОЙ (URL). Готового загрузчика
     файлов пока нет — нужно сначала загрузить фото куда-то (например, на
     хостинг изображений) и вставить ссылку.


==================================================================
11. БАЗА ДАННЫХ (важно знать)
==================================================================

Новости, вакансии и сообщения хранятся в базе PostgreSQL (сейчас —
бесплатный Supabase). Постоянный контент (структура, отделения и т.п.)
базу НЕ использует.

ОСОБЕННОСТЬ бесплатного Supabase: если базой долго не пользоваться
(~неделю), проект засыпает (ставится на паузу). Тогда:
   - на сайте не грузятся новости/вакансии;
   - сборка на Vercel может падать с ошибкой про базу.
РЕШЕНИЕ: зайти в дашборд Supabase и нажать «Resume» (разбудить проект),
затем при необходимости на Vercel нажать Redeploy.

Для постоянной работы лучше перейти на не засыпающую базу (Neon /
Vercel Postgres) или платный тариф — обсудите с разработчиком.


==================================================================
12. БЕЗОПАСНОСТЬ — ОБЯЗАТЕЛЬНО ПЕРЕД «БОЕВЫМ» ЗАПУСКОМ
==================================================================

Сейчас вход в админку — демонстрационный:
   • логин/пароль «зашиты» в коде (admin@aviales.kz / admin123);
   • страница панели /admin/dashboard пока НЕ защищена полноценной
     проверкой входа.
Перед тем как открывать сайт для всех, НУЖНО:
   1) сменить логин/пароль и сделать нормальную авторизацию;
   2) закрыть доступ к панели без входа.
Это задача для разработчика — отдельно сообщите, чтобы усилить защиту.


==================================================================
13. ХОСТИНГ / ПЕРЕДАЧА САЙТА
==================================================================

- Сейчас сайт хостится на Vercel и доступен по адресу
  aviales-site.vercel.app. Чтобы привязать собственный домен —
  в Vercel: Settings → Domains → добавить домен и прописать у
  регистратора домена DNS-записи, которые покажет Vercel.
- Если требуется размещение на сервере в Казахстане — нужен НЕ обычный
  «шаред»-хостинг (он под PHP), а VPS/VDS, где ставится Node.js +
  PostgreSQL. Настройку проводит разработчик.
- «Передача сайта» = передача доступа к: репозиторию GitHub, проекту
  Vercel, базе данных и домену.
