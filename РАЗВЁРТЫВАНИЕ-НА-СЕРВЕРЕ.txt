==================================================================
   РАЗВЁРТЫВАНИЕ САЙТА «КАЗАВИАЛЕСООХРАНА» НА СВОЁМ КОМПЬЮТЕРЕ
   ОС: UBUNTU DESKTOP (с рабочим столом)
==================================================================

Документ описывает, как с НУЛЯ поднять сайт на отдельном компьютере
под Ubuntu Desktop (есть рабочий стол, мышь, окна, браузер, VS Code).
Команды вводятся в приложении «Терминал» — их можно копировать
прямо из этого файла.

------------------------------------------------------------------
ЖЕЛЕЗО (то, что покупаете) — подходит с запасом:
   Intel 4–6 ядер, 8 ГБ ОЗУ, SSD 256/512 ГБ, белый СТАТИЧЕСКИЙ IP,
   подключение к ИБП (бесперебойнику).

БАЗА ДАННЫХ: ставим PostgreSQL прямо на этот компьютер.
   Почему именно его: сайт уже написан под PostgreSQL (через Prisma),
   поэтому КОД МЕНЯТЬ НЕ НУЖНО — вместо облачного Supabase будет
   локальная база, которая никогда не «засыпает».
   MySQL/MariaDB НЕ используем (потребовало бы переписывать сайт).

ИТОГОВЫЙ НАБОР ПРОГРАММ на компьютере:
   Ubuntu Desktop 24.04 LTS — операционная система с рабочим столом
   Node.js 20               — среда, в которой работает сайт
   PostgreSQL               — база данных (новости, вакансии, сообщения)
   PM2                      — держит сайт запущенным 24/7
   Nginx                    — принимает запросы из интернета (80/443)
   Certbot (Let's Encrypt)  — бесплатный SSL-сертификат (https)
   VS Code + Claude Code    — для редактирования и помощи (по желанию)


==================================================================
   ФАЗА 0. УСТАНОВКА ОС — UBUNTU DESKTOP
==================================================================

1) СКАЧАТЬ образ Ubuntu Desktop (на любом компьютере):
       https://ubuntu.com/download/desktop
   Выбрать «Ubuntu 24.04 LTS» → кнопка Download. Скачается файл .iso
   (около 5–6 ГБ). LTS = долгая поддержка, это и нужно.

2) ЗАПИСАТЬ образ на USB-флешку (8 ГБ и больше):
   - на Windows — программой Rufus (https://rufus.ie) или
     balenaEtcher (https://etcher.balena.io);
   - выбрать флешку, выбрать скачанный .iso, нажать Start/Flash.

3) ЗАГРУЗИТЬСЯ С ФЛЕШКИ:
   - вставить флешку в этот компьютер, включить;
   - при включении нажать клавишу входа в загрузочное меню/BIOS
     (обычно F12, F2, Del или Esc — зависит от материнской платы);
   - выбрать загрузку с USB.

4) ПРОЙТИ УСТАНОВЩИК (графический, с мышкой):
   - язык — Русский или English (на ваше усмотрение);
   - выбрать «Install Ubuntu»;
   - тип установки: «Normal installation»; галочки «Download updates»
     и «Install third-party software» — можно включить;
   - диск: «Erase disk and install Ubuntu» (если комп только под это);
   - создать пользователя: имя, логин (например admin), ПАРОЛЬ
     (обязательно запомнить — он же пароль для команд sudo);
   - дождаться установки, вынуть флешку, перезагрузить.

5) После загрузки вы увидите рабочий стол Ubuntu.
   ТЕРМИНАЛ открывается сочетанием Ctrl+Alt+T (или иконка «Terminal»
   в меню приложений). Все команды ниже вводятся в нём.

ЧТО ДЕЛАЕТ ТОЛЬКО ЧЕЛОВЕК (нельзя автоматизировать):
   - установка ОС и вход в BIOS (эта фаза);
   - у провайдера — получить белый статический IP;
   - на роутере — проброс портов 80 и 443 на этот компьютер;
   - у регистратора домена — прописать A-запись на ваш IP;
   - физически подключить ИБП.


==================================================================
   ФАЗА 1. БАЗОВАЯ НАСТРОЙКА
==================================================================
Открыть Терминал (Ctrl+Alt+T) и выполнить:

   sudo apt update && sudo apt upgrade -y
   sudo apt install -y git curl ufw

Фаервол (откроем только нужные порты):
   sudo ufw allow OpenSSH
   sudo ufw allow 'Nginx Full'
   sudo ufw enable

(Совет: чтобы открывать этот файл-инструкцию прямо на Ubuntu и копировать
команды — скопируйте его на флешку или откройте репозиторий на GitHub
в браузере Firefox, который уже есть в Ubuntu.)


==================================================================
   ФАЗА 2. NODE.JS
==================================================================
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs
   node -v && npm -v        (проверка — покажет версии)


==================================================================
   ФАЗА 3. POSTGRESQL (БАЗА ДАННЫХ)
==================================================================
   sudo apt install -y postgresql postgresql-contrib

Создать базу и пользователя:
   sudo -u postgres psql

Внутри (пароль придумать свой, сложный):
   CREATE DATABASE aviales;
   CREATE USER aviales_user WITH ENCRYPTED PASSWORD 'ПРИДУМАЙ_ПАРОЛЬ';
   GRANT ALL PRIVILEGES ON DATABASE aviales TO aviales_user;
   \c aviales
   GRANT ALL ON SCHEMA public TO aviales_user;
   \q


==================================================================
   ФАЗА 4. КОД САЙТА + НАСТРОЙКИ
==================================================================
   sudo mkdir -p /var/www && cd /var/www
   sudo git clone https://github.com/KingDanesa/aviales-site.git
   sudo chown -R $USER:$USER /var/www/aviales-site
   cd /var/www/aviales-site

Создать файл .env (откроется текстовый редактор nano):
   nano .env

Вставить (подставить пароль базы из Фазы 3):
   DATABASE_URL="postgresql://aviales_user:ПАРОЛЬ@localhost:5432/aviales?schema=public"
   DIRECT_URL="postgresql://aviales_user:ПАРОЛЬ@localhost:5432/aviales?schema=public"
   AUTH_SECRET="любая_длинная_случайная_строка"
   NEXTAUTH_SECRET="любая_длинная_случайная_строка"
   NODE_ENV="production"

Сохранить: Ctrl+O, Enter, Ctrl+X.

Установить, создать таблицы, собрать:
   npm install
   npx prisma generate
   npx prisma db push
   npm run build


==================================================================
   ФАЗА 5. ЗАПУСК САЙТА 24/7 (PM2)
==================================================================
   sudo npm install -g pm2
   pm2 start npm --name aviales -- start
   pm2 save
   pm2 startup     (выполнить команду, которую PM2 распечатает —
                    включит автозапуск после перезагрузки/света)

Проверка: pm2 status  — статус aviales должен быть "online".
Сайт уже работает на localhost:3000 (в браузере Ubuntu можно открыть
http://localhost:3000 и убедиться). Наружу откроет Nginx — Фаза 6.


==================================================================
   ФАЗА 6. NGINX (отдаёт сайт в интернет)
==================================================================
   sudo apt install -y nginx
   sudo nano /etc/nginx/sites-available/aviales

Вставить (заменить ваш-домен.kz на реальный домен; если домена ещё
нет — временно впишите IP сервера):

   server {
       listen 80;
       server_name ваш-домен.kz www.ваш-домен.kz;

       location / {
           proxy_pass http://localhost:3000;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
           proxy_cache_bypass $http_upgrade;
       }
   }

Включить:
   sudo ln -s /etc/nginx/sites-available/aviales /etc/nginx/sites-enabled/
   sudo rm -f /etc/nginx/sites-enabled/default
   sudo nginx -t && sudo systemctl reload nginx


==================================================================
   ФАЗА 7. ДОМЕН И ДОСТУП ИЗ ИНТЕРНЕТА (делает человек)
==================================================================
1) DNS у регистратора домена: запись A: @ -> ВАШ_СТАТИЧЕСКИЙ_IP
   (и www -> тот же IP).
2) Роутер: если компьютер за роутером — проброс портов (Port Forwarding)
   80 и 443 на локальный IP компьютера. Если белый IP назначен прямо
   на компьютер — проброс не нужен.
3) Проверить: открыть http://ваш-домен.kz — должен открыться сайт.


==================================================================
   ФАЗА 8. HTTPS (бесплатный сертификат)
==================================================================
Когда сайт открывается по http:
   sudo apt install -y certbot python3-certbot-nginx
   sudo certbot --nginx -d ваш-домен.kz -d www.ваш-домен.kz

Certbot сам включит https и будет автоматически продлевать сертификат.


==================================================================
   ФАЗА 9. БЭКАПЫ БАЗЫ
==================================================================
   sudo mkdir -p /var/backups/aviales
   crontab -e
Добавить строку (ежедневный дамп в 3:00):
   0 3 * * * pg_dump -U aviales_user -h localhost aviales > /var/backups/aviales/db_$(date +\%F).sql


==================================================================
   ФАЗА 10. VS CODE + CLAUDE CODE (по желанию, с графикой)
==================================================================
Так как у вас Ubuntu Desktop, можно поставить удобный редактор и
ИИ-помощника прямо с рабочим столом.

VS CODE (редактор кода):
   Способ 1 (проще): в терминале
       sudo snap install code --classic
   Способ 2: скачать .deb с https://code.visualstudio.com (кнопка для
       .deb / Debian, Ubuntu), затем дважды кликнуть по файлу и
       установить через «Центр приложений».
   После установки VS Code появится в меню приложений. Открыть папку
   проекта: File → Open Folder → /var/www/aviales-site

CLAUDE CODE (ИИ-помощник в терминале):
   sudo npm install -g @anthropic-ai/claude-code
   claude
   При первом запуске попросит войти (через браузер или API-ключ из
   console.anthropic.com). Нужен аккаунт Anthropic с оплатой
   (Claude Code платный по использованию).
   Удобно: открыть проект в VS Code и запускать claude в его
   встроенном терминале (Terminal → New Terminal).

==================================================================
   ВАРИАНТ «СДЕЛАЙ САМ» — ПОРУЧИТЬ НАСТРОЙКУ CLAUDE CODE
==================================================================
После установки Claude Code (Фаза 10) можно поручить ему Фазы 1–9.
Запустите в терминале:  claude
и вставьте промпт (подставьте свой пароль базы и домен):

-------- НАЧАЛО ПРОМПТА --------
Ты разворачиваешь продакшен-сайт на этом компьютере с Ubuntu 24.04.
Действуй по шагам, объясняй что делаешь, команды с sudo запускай сам
(я рядом и введу пароль, когда попросишь).

1. Установи (если ещё не стоят): Node.js 20, Git, Nginx, PostgreSQL,
   PM2 (глобально), certbot с плагином nginx, ufw.
2. Настрой ufw: разреши OpenSSH и 'Nginx Full', включи его.
3. В PostgreSQL создай базу "aviales" и пользователя "aviales_user"
   с паролем "ВСТАВЬ_ПАРОЛЬ_БАЗЫ", выдай ему все права на базу и на
   схему public.
4. Склонируй https://github.com/KingDanesa/aviales-site.git в
   /var/www/aviales-site и сделай меня владельцем папки.
5. Создай .env в проекте: DATABASE_URL и DIRECT_URL на локальную базу
   aviales (postgresql://aviales_user:ВСТАВЬ_ПАРОЛЬ_БАЗЫ@localhost:5432/aviales?schema=public),
   AUTH_SECRET и NEXTAUTH_SECRET — случайные длинные строки,
   NODE_ENV=production.
6. Выполни: npm install, npx prisma generate, npx prisma db push,
   npm run build.
7. Запусти сайт через PM2 под именем "aviales" (npm start),
   pm2 save и настрой автозапуск (pm2 startup).
8. Настрой Nginx реверс-прокси с домена "ВСТАВЬ_ДОМЕН" на
   http://localhost:3000, проверь конфиг и перезапусти Nginx.
9. Пока оставь http (без SSL). Я сообщу, когда домен будет указывать
   на этот компьютер, чтобы выпустить сертификат через certbot.
В конце выведи pm2 status и проверь, что сайт отвечает на localhost:3000.
-------- КОНЕЦ ПРОМПТА --------

Когда домен привяжут (Фаза 7), снова запустите claude и скажите:
«Выпусти SSL-сертификат через certbot для домена ВСТАВЬ_ДОМЕН и включи
https в Nginx».

ЧТО CLAUDE CODE НЕ СДЕЛАЕТ (только человек): установка ОС/BIOS,
белый IP у провайдера, проброс портов на роутере, DNS у регистратора,
подключение ИБП. Он также спрашивает разрешение на команды — подтверждайте.


==================================================================
   ВАЖНЫЕ ЗАМЕЧАНИЯ
==================================================================
1) Перед боевым запуском заменить демо-вход в админку (логин/пароль
   сейчас зашиты в коде) на нормальную авторизацию — правка кода,
   делает разработчик.
2) После переезда сайт живёт на вашем компьютере; Supabase и Vercel
   больше не нужны (Vercel можно оставить как запасную копию).
3) Уточнить у провайдера: IP именно «белый» статический (не «серый»
   за NAT) и порты 80/443 не заблокированы — иначе сайт снаружи
   не откроется.
4) ИБП обязателен; автозапуск после перезагрузки уже настроен (PM2).
5) Не выключайте компьютер — это сервер, он должен работать постоянно.
